# 🚀 My Backend Learning Journey - First Express Server

This repository marks my first step into backend development. Here, I have built a basic REST API server using Node.js and the Express.js framework.

## 📚 About The Project

This is a simple server that currently supports only one route. Although it is small right now, I plan to add database connections, authentication, and more complex API features in the future.

### 🔧 Built With

*   [Node.js](https://nodejs.org/)
*   [Express.js](https://expressjs.com/)
*   JavaScript (ES6)
